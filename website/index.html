Privacy & Security

On-Device & Local First

FocusGuard is designed as a personal, on-device productivity tool. It requires Android system permissions strictly to monitor foreground app transitions and display the overlay screen.

  • No user accounts or cloud sign-in required.
  • Tasks and blocked app lists are stored locally in Room SQLite database.
  • Usage Access permission is evaluated locally to check foreground package names.
